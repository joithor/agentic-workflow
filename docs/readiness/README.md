# Readiness

Agent-readiness measurements for this repo (spec: `docs/superpowers/specs/2026-10-09-agent-readiness-design.md`).

| File | What it is |
|---|---|
| `baseline-2026-10.md` | The R0 baseline: each criterion scored from what the repo shows, per pillar and per app |

The baseline is generated by `scripts/readiness-baseline.mjs`, a **throwaway** script (Node ≥ 20, no
dependencies). `Aw.Readiness` replaces it in R1b and becomes the score of record (decision R4). No paid Factory
report or Droid is used.

It is **not** the §8 output contract, so don't wire it into CI as one. It has no `--json` (versioned schema), no
delta since the last run and no "first run records a baseline"; it writes nothing to the ledger; its rows give the
measured value and evidence but no limit or fix command; and its exit codes mean 0 = report written and
2 = tool error, not 0 = target level holds and 1 = it doesn't. `Aw.Readiness` implements those and diffs its first
run against `baseline-2026-10.md` as the previous run.

```bash
node scripts/readiness-baseline.mjs --out docs/readiness/baseline-2026-10.md   # regenerate (reads gh api, GET only)
node scripts/readiness-baseline.mjs --no-remote                                # offline: remote criteria → unknown
bash scripts/tests/readiness-baseline.test.sh                                  # tests on fixture trees
```
