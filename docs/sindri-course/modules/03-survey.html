Call before you dig

Before a crew digs, a surveyor marks every buried pipe and cable with paint. Hitting one mid-dig is how a two-day job becomes a two-week one. Projects sprawl the same way, when the surfaces and implications are found during implementation.

No paint mark without a source

The model drafts the map, but code checks it. A surface that cites nothing, or cites something that isn't a real source, is rejected:

sindri/src/scope/map.ts 
  for (const s of map.surfaces) {
    if (seen.has(s.id)) reasons.push(`duplicate surface id ${s.id}`);
    seen.add(s.id);
    if (s.citations.length === 0) reasons.push(`surface ${s.id} cites no source`);
    for (const c of s.citations) if (!known.has(c)) reasons.push(`surface ${s.id} cites ${c}, which is not a source reference`);
    if (!inStream.has(s.id)) reasons.push(`surface ${s.id} is in no workstream`);

Walk every surface the model proposed.

The same id twice? Write down why that's wrong.

Remember we've seen this one.

No citation at all: rejected.

A citation the model invented (not a real source): rejected. This is how hallucinated references get caught.

A surface no workstream owns would fall through the cracks: rejected.

The full check also refuses dependency cycles and workstreams without acceptance checks. Then a different model runs an adversarial "what's missing?" pass until nothing new appears.

Proving it on yesterday's projects

How do you know the surveyor is any good? Hand it an old project's original brief, with sources cut to that date, and compare its map to the issues people actually filed later. That's the backtest.

Adjudicator, twice, order reversed

A model labels matches, never a person (invariant 9). Only answers that agree in both orders count.

sindri/src/scope/backtest.ts 
  const recall = verdict(r, PASS_BAR.recall);
  const precision = verdict(p, PASS_BAR.precision);
  const beatsBaseline: Verdict = r === null || b === null ? "not measured" : r > b ? "met" : "not met";
  const all = [recall, precision, beatsBaseline];
  const overall = all.includes("not measured") ? "NOT MEASURED" : all.every((v) => v === "met") ? "PASS" : "NOT PASSED";

Recall must reach the bar (0.60)…

…and so must precision.

Sindri must also find more than the brief alone would. If either number is missing, say so.

Collect the three verdicts.

Any unknown → NOT MEASURED, never a quiet pass. All met → PASS.

Scoping v2: a surveyor who keeps digging designed

Today's challenger only re-reads the drafter's evidence, so it can only find what was already gathered. In v2, each round the challenger writes typed expansion queries, Sindri runs them, and the drafter revises with only the new evidence. Weak surfaces get pruned with a reason. Removals leave a tombstone

A removed item leaves a tombstone, so the loop doesn't re-propose it without new evidence. Human adds are never pruned. And because labels come from the net difference at freeze, removing and then restoring something teaches nothing wrong.
