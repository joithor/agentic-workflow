The capability ceiling

Prompt text (instructions, rubrics, rule wording) may improve itself. Capability fields (tool, command, MCP, network, write-scope and budget allowlists) are always approval-tier. No model output may set them. §17.19 C1–C2

Lenses: the film crew's departments

Sound doesn't light the set, and lighting doesn't mix audio. A lens is a discipline with its own questions, rules, tools and evidence. Workflow generation picks the lenses once per deliverable, then freezes the order. §17.7

Taste, written down

"I always want X", said once at the desk, becomes a rule: the style bible a director hands each department. Selectors mean a session carries only the few that apply. §17.6

Sessions don't edit the tests that judge them

Existing tests are read-only unless the packet names the change (invariant 17), and every new test must fail with the non-test changes reverted. Otherwise an agent can "go green" by weakening an assertion.
