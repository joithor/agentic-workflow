9

What the app never does

§6.5
Never
  • Run agent text, show it as anything but plain text, or put item text in a launch command.
  • Decide on an agent's behalf: it acts on a human click or key, never on a stream event.
  • Approve a protected action. Grants, accepts, recipe and profile approvals and map-review apply are copy-the-CLI only (cli-only:typed-confirmation).
  • Resume a session that's still running, or start two processes on one session.
  • Start the control plane from the window (bare sindri does), or start an agent without a click.

The handler never does slow work: opening an app is I/O, so it runs in the launcher service. The app re-reads views on each event; it holds no launch logic.
